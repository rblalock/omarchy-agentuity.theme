# Agentuity theme for Omarchy

A theme for www.agentuity.com

## To install:

1. Copy the theme repository URL
2. Click `SUPER + ALT + SPACE`
3. Click `Install`
4. Click `Style`
5. Click `Theme`
6. Paste the link and hit enter to submit

### 2nd way to install

`omarchy-theme-install https://github.com/rblalock/omarchy-agentuity.theme`
